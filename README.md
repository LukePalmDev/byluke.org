# byluke.org

Sito personale di Luke Palmieri. Pagine statiche servite da GitHub Pages.

I progetti stanno in [`projects.json`](projects.json): nome, descrizione, tag, URL del sito e URL del repository. Per puntare un progetto a un sottodominio basta cambiare il suo `liveUrl`.

Anteprima locale:

```bash
python3 -m http.server 8765
```

Poi apri `http://127.0.0.1:8765`.
